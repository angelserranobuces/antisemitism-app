🔒 About data storage

All analysis results are saved automatically in your browser's local storage after each analysis. Data persists across sessions as long as you use the same browser on the same device.

To back up or move your data, use the Export JSON button above. To restore on another device or browser, use Import JSON. Data is stored under the key framing_risk_history_v2.
